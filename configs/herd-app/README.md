# Herdr App configuration

Personal Herdr desktop app configuration, stored in the layout, keys, settings, theme, fonts, and custom mods. Copy these files into ~/.config/herdr-app/ to use them. Herdr rewrites its shipped layouts and mods, so only the custom files listed here are tracked.

The custom mods include JavaScript and Python source, fixtures, tests, and SVG artwork. Generated type declarations and Python bytecode are excluded. Font license texts are included beside the bundled font files.
